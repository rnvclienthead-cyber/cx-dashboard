## HTML шаблон (вставить в начало `<template v-else-if="activeSection==='processes'">`)

Полный код диаграммы был в DocsView.vue — можно восстановить из git или из этого беклога.  
Основная структура:
- Зелёная полоса-заголовок
- Левая панель: легенда RACI (R/A/C/I) + блок участников
- 5 колонок этапов: RACI-бейджи → этап-бокс → подпроцессы
- Строка «Смысл» (жёлтая)
- Строка «Результат» (зелёная)  
- Строка «Отчёты/инструменты» (синяя)
