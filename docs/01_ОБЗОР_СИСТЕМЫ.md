# CX Dashboard — Обзор системы

> **Последнее обновление:** июнь 2026  
> Система автоматизации клиентского опыта для работы с возвратами, отзывами и аналитикой дефектов на маркетплейсах WB, Яндекс Маркет и OZON.

---

## 1. Назначение

CX Dashboard — внутренний инструмент для команды, который:

- **Собирает автоматически** все возвраты, отзывы и заказы с трёх маркетплейсов
- **Тегирует с помощью ИИ** причины возвратов и тональность отзывов
- **Считает PPM** (дефекты на миллион) и генерирует претензионные акты (PDF) для производства
- **Управляет доотправками** — от триггера в WB-чате до отправки через СДЭК
- **Показывает руководству** ключевые метрики: потери, CSAT, топ-проблемные SKU

## 3. Технологический стек

| Компонент | Технология | Где находится |
|-----------|-----------|---------------|
| Фронтенд | Vue.js 3 + Vite | `/var/www/cx-dashboard/` на сервере |
| Бэкенд | Python 3 + FastAPI | `/root/cx-dashboard/` на сервере |
| База данных | PostgreSQL | `cx_dashboard` на сервере |
| Веб-сервер | Nginx | реверс-прокси к порту 8000 |
| Хранилище фото | Яндекс Object Storage (S3) | бакет `cx-dashboard-media` |
| Автоматизация | systemd + cron | на сервере |

## 4. База данных — ключевые таблицы

### WB (Wildberries)
| Таблица | Что хранит |
|---------|-----------|
| `wb_claims` | Возвраты WB (рекламации), теги ИИ, результаты модерации |
| `wb_feedbacks` | Отзывы покупателей WB |
| `wb_orders` | Заказы WB |
| `wb_logistics` | Логистика WB (финансовые данные по SRID) |
| `wb_invoices` | Инвойсы (связь поставка → артикул → номер инвойса) |
| `wb_cogs` | Себестоимость (cost of goods) по артикулу и инвойсу |
| `wb_assortment` | Ассортимент (матрица товаров, категории) |
| `wb_chat_pending` | Ожидающие триггеры WB-чата (доотправки) |

### Яндекс Маркет
| Таблица | Что хранит |
|---------|-----------|
| `ym_orders` | Заказы ЯМ |
| `ym_returns` | Возвраты ЯМ |
| `ym_feedbacks` | Отзывы ЯМ |
| `ym_prices` | Цены товаров ЯМ |

### OZON
| Таблица | Что хранит |
|---------|-----------|
| `ozon_returns` | Возвраты OZON (FBO) |
| `ozon_orders` | Заказы OZON |

### Общие / Система
| Таблица | Что хранит |
|---------|-----------|
| `users` | Пользователи системы (email + хэш пароля + роль) |
| `allowed_emails` | Белый список для приглашений |
| `roles` | Роли (системные и пользовательские) |
| `role_permissions` | Права роли: какой модуль × какой маркетплейс |
| `system_logs` | Журнал действий воркеров |
| `reshipment_requests` | Заявки на доотправку |
| `ppm_claims_log` | Реестр претензионных актов PPM |

## 5. Роли пользователей

| Роль | Описание | Доступ |
|------|----------|--------|
| `admin` | Администратор | Всё, включая управление пользователями |
| Настраиваемые | Создаётся в панели Admin | Набор модулей × набор маркетплейсов |

Права настраиваются гранулярно: например, роль "Менеджер WB" может видеть модули `reshipment` и `moderation` только по маркетплейсу `wb`.

## 6. Воркеры (автоматическая синхронизация)

| Воркер | Расписание | Что делает |
|--------|-----------|-----------|
| `worker.py hourly` | каждые 2 ч | WB: возвраты + отзывы |
| `worker.py daily` | 03:00 | WB: заказы, ассортимент, логистика, инвойсы |
| `ym_worker.py hourly` | каждые 2 ч | ЯМ: заказы, возвраты, отзывы, вопросы |
| `ym_worker.py daily` | 03:00 | ЯМ: ассортимент, цены, запуск финотчётов |
| `ym_worker.py reports` | 05:00/09:00/13:00 | ЯМ: скачивание готовых отчётов |
| `ozon_worker.py hourly` | каждые 2 ч | OZON: возвраты, статусы |
| `ozon_worker.py daily` | 03:00 | OZON: заказы (30-дн. окна) |
| `ai_tagger.py` | по запросу / cron | ИИ-теги на необработанные записи |
| `wb_chat.py` (asyncio) | постоянно в бэкенде | Мониторинг WB-чата, триггер `#от` |
