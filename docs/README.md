## Как устроен интерфейс (коротко)

Меню слева разбито на 4 блока: **🔧 Технический**, **📊 Операционный**, **💬 Функциональный**, **⚙️ Административный**. Наверху — Главный дашборд и переключатель площадки (WB / ЯМ / OZON). Каждый пользователь видит только разрешённые ему разделы. Подробно — [02_МОДУЛИ.md → Как устроен интерфейс](02_МОДУЛИ.md#как-устроен-интерфейс).
