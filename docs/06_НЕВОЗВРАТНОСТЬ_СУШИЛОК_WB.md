# Невозвратность сушилок на Wildberries

Краткая справка для шаблонов чата (тема `nevozvratny`, правило только WB).

## Вывод

**Жёсткого пункта закона «сушилка для белья не подлежит возврату» нет.**
Сушилки **не входят** в классический Перечень непродовольственных товаров надлежащего качества, не подлежащих возврату или обмену (утв. постановлением Правительства РФ № 55).

Практика «товар невозвратный» для сушилок у продавца опирается на **правила/карточку Wildberries** (возвратность, которую определяет площадка), а не на отдельную статью ЗоЗПП про сушилки. В ответах клиенту **не ссылаться** на несуществующий «пункт закона про сушилки» — формулировка как в шаблоне: возвратность определяет WB / отказаться можно было при получении.

На **Ozon и Яндекс Маркет** это правило **не применяем** (бот ведёт в обычный возврат площадки).

## Нормативная база (для ориентира)

| Документ | Что даёт |
|----------|----------|
| [ПП РФ № 55](https://www.consultant.ru/document/cons_doc_LAW_13612/) — Перечень товаров, не подлежащих возврату/обмену | Список категорий (гигиена, бельё, парфюмерия, мебель бытовая определённых видов и т.д.). Сушилки для белья как отдельная позиция **не названы**. |
| [ст. 26.1 ЗоЗПП](https://www.consultant.ru/document/cons_doc_LAW_305/) — дистанционная продажа | Право отказаться от товара надлежащего качества в сроки закона, **кроме** товаров с индивидуально-определёнными свойствами (если изготовлен/подобран под покупателя). |
| Правила / справка WB по возврату | Фактический UX кнопки «Вернуть» и пометки возвратности на карточке — источник для клиента; решение по заявке принимает площадка. |

## Что писать в шаблонах

- OK: «возвратность определяет Wildberries», «отказаться можно было при получении».
- Не OK: «согласно постановлению №… сушилки невозвратные».

Список категорий в системе: API `/api/v1/nonreturnable-cats` (по умолчанию «Сушилки для белья»), срабатывает только при `mp=wb`.
